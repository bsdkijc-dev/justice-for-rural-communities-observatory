# Changelog

All notable changes to the Justice for Rural Communities Observatory (JRC Observatory) are documented in this file.

## [0.1.0] - 2026-11-23
### Added
- Initialized repository structure (`governance/`, `research/`, `schemas/`, `sources/`, `data/`, `notebooks/`, `src/`, `reports/`, `public_knowledge/`, `dashboard/`, `website/`, `tests/`, `.github/workflows/`).
- Authored governance framework (`research-charter.md`, `data-governance.md`, `privacy-policy.md`, `publication-policy.md`, `ethics-protocol.md`, `source-verification-policy.md`, `risk-register.md`).
- Authored research design documents (`research-questions.md`, `conceptual-framework.md`, `methodology.md`, `hypotheses.md`, `indicator-dictionary.md`, `limitations.md`).
- Created 12 JSON Schema (Draft 2020-12) files for Datasets 01–12.
- Created `sources/source-register.csv`, `sources/source-assessment.md`, and `sources/legal-authorities.md` with verified Indonesian public sources.
- Generated `P5` synthetic sample datasets (`data/synthetic/`) and automated validation test suite (`tests/test_validation.py`, `src/validation/validate_all.py`).
- Added CI workflow (`.github/workflows/validate.yml`).
